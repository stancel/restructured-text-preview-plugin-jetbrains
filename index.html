ReStructuredText Preview

Live HTML preview for .rst files in any JetBrains IDE — no Python plugin required.

Features

✎

Live Preview

See rendered HTML update as you type, with a split-pane editor showing source and preview side by side.

🎨

Theme Support

Automatic dark and light theme switching that matches your IDE appearance, with styled admonitions.

🖨

Print Preview

Print rendered RST documents directly from the IDE with optimized print styling.

🔧

No Python Required

Uses your system's rst2html from docutils directly — no Python plugin dependency.

🌐

JCEF Rendering

High-quality HTML5/CSS rendering via embedded Chromium, with Swing fallback for unsupported platforms.

⚙

Auto-Detection

Finds rst2html automatically from pyenv, PATH, and common install locations.

Requirements

  • Any JetBrains IDE 2024.3 or newer (build 243–261.*)
  • docutils installed with rst2html available
pip install docutils
